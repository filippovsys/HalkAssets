## О проекте

HalkAssets — настольное приложение для учёта и инвентаризации основных средств
в банковском филиале. Работает локально или на сетевой папке (несколько
пользователей с блокировкой «один активный сеанс»).

**Главная идея:** вместо того чтобы вручную искать технику в огромной таблице
Excel, сотрудник берёт сканер штрих-кодов, подходит к кабинету, сканирует
наклейку на двери — и программа сама показывает список активов этого кабинета.
Дальше просто сканирует каждый актив: у кого отметка обновилась — тот найден,
у кого нет — потерян.

### Основные возможности

- 📦 **Учёт активов** — карточка с инвентарным номером, категорией, местом,
  ответственным, серийным номером, датой покупки, стоимостью и остаточной
  стоимостью.
- 🔍 **Инвентаризация сканером** — штрих-код на каждом активе, скан
  обновляет «последнее сканирование» и подсвечивает строку в таблице.
- 🚪 **Метки кабинетов** — на двери клеится метка `LOC-<id>`. Скан метки
  автоматически ставит фильтр по кабинету — не нужно искать в списке.
- 🗂 **Справочники** — категории, места, сотрудники. Авто-добавление
  значений при вводе, массовое добавление, переименование с обновлением
  всех связанных карточек.
- 🕓 **История перемещений** — каждая смена места или ответственного
  записывается в `movement_history` и доступна из карточки.
- 📊 **Дашборд** — сводка: количество активов, суммы, распределение по
  категориям и местам, «давно не сканировалось», последние действия.
- 🖨 **Печать штрих-кодов** — Code128 на термопринтере этикеток
  (4BARCODE 3B-320B и совместимые), с правильным размером под реальное DPI
  принтера.
- 📄 **Отчёты в PDF** — акт инвентаризации, журнал списанных активов,
  с шапкой филиала и подписями.
- 📥 **Импорт/экспорт Excel** — единый шаблон, файл экспорта всегда
  импортируется обратно.
- 🧾 **Импорт из бухгалтерии** — ведомость амортизации из 1С, автоматическое
  сопоставление по инвентарному номеру, автосписание пропавших активов.
- 🗑 **Корзина (мягкое удаление)** — удалённые карточки не теряются,
  их можно восстановить.
- 👤 **Авторизация** — локальные пользователи + опциональная проверка через
  Active Directory с кэшем для работы на ноутбуке без сети.
- 🔐 **Аудит действий** — журнал всех значимых операций (вход, создание,
  редактирование, удаление, импорт, печать) с фильтрами и экспортом в Excel.
- 🏢 **Настройка филиала** — название филиала выводится в шапке PDF-отчётов.

## Установка

### Требования

- **Windows** 10/11
- **Python** 3.11 или новее (рекомендуем 3.13)
- Сканер штрих-кодов, эмулирующий клавиатуру (любой USB-сканер подходит)
- Термопринтер этикеток для печати штрих-кодов (опционально)
